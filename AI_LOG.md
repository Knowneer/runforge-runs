Отчёт об использовании AI (AI_LOG)

1. Инструменты и модели

В процессе разработки использовался AI-ассистент (Google Gemini) для проектирования архитектуры компонентов, написания логики фильтрации и генерации юнит-тестов.

2. Ключевые запросы и переданный контекст

1.Структурирование компонентов и UI-кита:

Контекст: Требования к изоляции стилей через CSS Modules и модульной архитектуре.
Запрос: «Помоги спроектировать переиспользуемые компоненты MyButton, MyInput и фирменный MyLoader с использованием CSS Modules и переменных темы Runforge».

2.Написание логики совместного поиска и фильтрации:

Контекст: Наличие стейтов searchQuery, selectedStatus и массива запусков.
Запрос: «Напиши оптимизированный хук useMemo для фильтрации массива запусков по статусу и поисковому запросу с подсчётом количества элементов для бейджей на кнопках».

3.Настройка автотестов на Vitest:

Контекст: Необходимость покрыть тестами поиск, фильтрацию и открытие деталей.
Запрос: «Составь юнит-тесты на React Testing Library и Vitest для проверки фильтрации по статусу, работы поиска и открытия панели деталей запуска с моком данных».

3. Найденные ошибки AI и ручные исправления

Конфликт селекторов при поиске элементов в тестах: AI предложил искать кнопку статуса через `screen.getByRole('button', { name: /Succeeded/i })`. Однако на странице оказалось несколько интерактивных элементов с таким текстом (кнопка фильтра сверху и карточка запуска в списке), что вызвало ошибку `Found multiple elements`.

*Исправление:* Использован метод `screen.getAllByRole('button', { name: /Succeeded/i })[0]` для точного обращения к кнопке фильтрации в верхней панели, а также добавлена директива `// @vitest-environment jsdom` для корректной работы глобального объекта `window` в тестовой среде.

Обработка отсутствующих опциональных полей (durationSeconds): В карточках и деталях для запусков со статусом queued длительность изначально не возвращалась, что приводило к выводу undefined.

Исправление: Добавлена защитная функция formatDuration, которая проверяет наличие числового значения и выводит прочерк —.
